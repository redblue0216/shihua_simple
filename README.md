# shihua's personal project landing page

This is shihua's personal project landing page, which is used to archive and organize all personal projects.

---

## Tech Stack

| Technology    | Version | Purpose                                   |
|---------------|---------|-------------------------------------------|
| React         | 19.x    | UI component library                      |
| TypeScript    | 7.x     | Static type checking and DX               |
| Tailwind CSS  | 4.x     | Utility-first styling and dark mode       |
| Vite          | 8.x     | Fast development server and build tooling |
| Oxlint        | 1.x     | Linting                                   |

## How to Build

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

Then open http://localhost:4174 in your browser.

### 3. Build for production

```bash
npm run build
```

The static output will be generated in the `dist/` directory.

### 4. Preview the production build

```bash
npm run preview
```

### 5. One-click production build

To perform a clean install followed by a production build, run:

```bash
npm run build:prod
```

This script performs a clean dependency install with `npm ci` and then builds the project for production.

> ⚠️ Use `build:prod` only when you want a clean install from `package-lock.json`. During active development, use `npm run build` instead.
